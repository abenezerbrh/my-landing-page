Smart Braille Learning and Translation Assistant

An embedded assistive device built on the NXP FRDM-K66F that teaches and translates braille interactively. A 6-button grid mirrors the standard braille cell, an OLED and LED array mirror the pattern, and a DFPlayer Mini speaks each letter aloud. An ESP32 bridges the device to a live Flask dashboard over WiFi, where Google Gemini analyzes quiz performance and generates personalized learning recommendations across translation, word formation, and quiz modes.
