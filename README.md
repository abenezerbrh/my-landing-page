Personal portfolio site

**Live site:** [abenezerbrh.github.io/my-landing-page](https://abenezerbrh.github.io/my-landing-page)

## Overview

A single-page portfolio built with plain HTML, CSS, and JavaScript. No build step or framework, just one `index.html` file that anyone can open directly or serve as a static site.

The page covers:

- **Home** — intro, and quick links
- **Experience** — internship and job history
- **Projects** — featured work
- **About** — background and quick stats
- **Skills** — grouped by Languages, Web, Embedded, and Tools
- **Education** — degree info and relevant coursework
- **Contact** — email, LinkedIn, and a contact form

## Tech

- HTML5 / CSS3 (custom properties, CSS Grid, no framework)
- Vanilla JavaScript (scroll-based nav highlighting via `IntersectionObserver`)
- [Font Awesome](https://fontawesome.com/) for icons
- [Devicon](https://devicon.dev/) for technology logos
- Google Fonts (DM Sans, DM Mono)

## Running locally

No build tools needed. Clone the repo and open `index.html` in a browser, or serve it locally:

```bash
git clone https://github.com/abenezerbrh/my-landing-page.git
cd my-landing-page
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
